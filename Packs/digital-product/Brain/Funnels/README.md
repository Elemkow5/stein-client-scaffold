# Funnels

One file per funnel. Each file is the approved map for that product's 7-piece funnel — created by `/funnel-map` before any pages are built.

## Files in this folder

- `[product-name].md` — funnel map for that product (created by `/funnel-map`)

## How to use

- Run `/funnel-map` to create a new funnel map
- Run `/funnel-edit` to safely change a live funnel page
- Run `/funnel-recover` to wire up lost-cart recovery for a funnel
