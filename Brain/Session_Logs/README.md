# Session Logs

One file per session. Format: `YYYY-MM-DD-HHhMM.md`

Each file captures: what was discussed, decisions made, tasks completed, open threads, next steps.

The compounding layer — day 1 vs. month 6 is a completely different system because of what's here.

## File Structure

```
# Session — YYYY-MM-DD HH:MM

## Context (from previous session)

## Session Log

## Decisions Made

## Tasks Completed

## Todos

## Open Threads

## Next Steps
```
